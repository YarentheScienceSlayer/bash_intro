# Bash Scripting Introductory Lessons

This repository contains a Bash scripting lesson series prepared for bioinformaticians. Lessons are provided in PDF format, and each lesson is supported by a dataset you can use to practice the commands covered.

## How to Study

You can work through the lessons in two ways:

1. **Studying from the PDFs:** The content for each lesson is provided in its corresponding PDF file. It is recommended to follow the lessons in order.
2. **Practicing in a Codespace:** You can open this repository as a GitHub Codespace and try out the commands you learn in each lesson directly in the terminal, using the sample data in the `data` folder. To open a Codespace, click the "Code" button on the repository page and start a new Codespace from the "Codespaces" tab.

## Homework

Each lesson has a corresponding homework assignment. You can find the assignment questions and submission instructions at the following website:

**https://yarenthescienceslayer.github.io/bash_intro/Homeworks/index.html**


## Lesson Contents

- **Lesson 1:** Introduction to Bash
- **Lesson 2:** File manipulation and regex
- **Lesson 3 and onward:** Loops and environment variables
