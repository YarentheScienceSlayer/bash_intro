🚀 Navigation with cd

The Power of cd - and cd ~

cd ~ takes you back to your home directory. This is useful when you're lost in deep directories.

cd - takes you back to the PREVIOUS directory you were in. Super useful for switching between two places!

$ cd /very/deep/path/to/data
$ cd /another/deep/path/to/results
$ cd -          # Jump back to /very/deep/path/to/data
$ cd -          # Jump back to /another/deep/path/to/results (alternates)

📖 Reading Files

Different Ways to Read Files

Depending on what you need, use different commands:

  • head -n 10 file.txt → First 10 lines
  • tail -n 5 file.txt → Last 5 lines
  • tail -n +2 file.txt → All lines EXCEPT the first
  • cat file.txt → All lines (use with caution on huge files!)
  • less file.txt → Page through file (press q to quit)

🧬 Counting Reads in FASTQ Files

Why This Matters in Bioinformatics

FASTQ files store sequencing reads. Each read takes exactly 4 lines:

  • Line 1: Sequence ID (starts with @)
  • Line 2: DNA sequence
  • Line 3: Plus sign (+)
  • Line 4: Quality scores

Formula: Number of reads = Total lines ÷ 4

🔀 Piping and Redirection

The Difference: > vs >>

  • > = Overwrite the file (destroys old content!)
  • >> = Append to the file (keeps old content)
$ ls > files.txt              # Creates OR overwrites files.txt
$ ls >> files.txt             # Appends to files.txt
$ cat data.txt | wc -l        # Pipe: send output as input to next command

The Pipe (|)

Chain commands together! Output of left command → input of right command:

$ cat huge_file.txt | wc -l    # Count lines (efficient for huge files!)
$ cat data.txt | grep "error" | head -5  # Find "error" lines, show first 5

🔎 Searching with grep

The grep Command

grep searches for patterns in text. Essential for bioinformatics!

$ grep "sequence_id" file.txt          # Find lines containing "sequence_id"
$ grep -i "ERROR" log.txt              # Case-insensitive search (-i)
$ grep -c "found" file.txt             # Count matching lines (-c)
$ grep "@" reads.fastq | head          # Show first 10 sequence IDs from FASTQ
$ grep -v "^#" data.txt                # Show all lines EXCEPT comments (-v)
$ grep "pattern" file.txt | wc -l      # Count matches

📄 Paging Through Files with less

Why Use less?

For huge files, cat will overflow your terminal. Use less to page through:

$ less huge_file.fastq
   Inside less:
   Space or Page Down → next page
   b or Page Up       → previous page
   / pattern          → search for pattern
   n                  → next match
   N                  → previous match
   G                  → end of file
   g                  → beginning of file
   q                  → quit
