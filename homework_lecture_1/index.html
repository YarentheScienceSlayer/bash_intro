Check Answer Show Hint 🔀 Piping and Redirection The Difference: > vs >> • > = Overwrite the file (destroys old content!) • >> = Append to the file (keeps old content) $ ls > files.txt # Creates OR overwrites files.txt $ ls >> files.txt # Appends to files.txt $ cat data.txt | wc -l # Pipe: send output as input to next command The Pipe (|) Chain commands together! Output of left command → input of right command: $ cat huge_file.txt | wc -l # Count lines (efficient for huge files!) $ cat data.txt | grep "error" | head -5 # Find "error" lines, show first 5 Challenge 16: Append to File Add More Data Without Destroying Old Data Write a command to append the contents of new_data.txt to existing_data.txt.
